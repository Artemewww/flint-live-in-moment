# ⚠️ ЛЕГАСИ-КОД — НЕ ИСПОЛЬЗУЕТСЯ

Эта папка содержит **устаревший код бота** для запуска через **polling на VPS**.

## 🚫 Почему не работает

Telegram блокирует `getUpdates` (polling), если установлен webhook. Сейчас бот работает через **webhook на Vercel** (`api/telegram/webhook.ts`).

## ✅ Актуальный код бота

**Файл**: `/api/telegram/webhook.ts` (2070 строк)  
**Режим**: Webhook на Vercel  
**Деплой**: автоматически через `git push origin main`

## 📚 Использование

Код здесь можно использовать как **референс** при разработке новых хендлеров, но **не запускать напрямую**.

Чтобы вернуться на polling:
1. Удалить webhook: `curl https://api.telegram.org/bot<TOKEN>/deleteWebhook`
2. Запустить бота: `cd bot.legacy && npm start`
