# 🚀 Новые функции Flint Bot — Полная автоматизация

## 📋 Что добавлено

### 1. ⚠️ **Техника безопасности с обязательным подтверждением**
- Каждое мероприятие имеет свой набор правил безопасности (location-specific)
- Все участники должны подтвердить ознакомление перед выездом
- Тезисные правила: никаких лент текста, только чёткие пункты
- Автоматические напоминания неподтвердившим (за 24ч до события)

**Пример для Любаньских карьеров:**
- ❗ Никто один не ходит (особенно на экскурсии)
- 🏕 Лагерь разбиваем в лесу
- 🚫 Купание в меловых карьерах запрещено
- 📱 Связь: телефон заряжен, координатор на связи

**Миграция:** `2026-safety-briefing.sql`

---

### 2. 🛒 **Коллективная закупка еды с ИИ-помощником**
- Участники пишут пожелания **свободным текстом** ("хочу молока, шоколада")
- ИИ парсит → категории (молочка, сладости, напитки...) + конкретные продукты
- Выбор из чек-листа категорий ИЛИ свободный текст
- Дедлайн: кто успел присоединиться — тот участвует
- Умная рассылка: только тем, кто БЕЗ своей еды (автофильтр по анкетам)
- Админ может вручную добавить передумавших
- Назначается закупщик → все скидывают → чек → сплит

**Работает в моменте:** на поляне кто-то пишет "давай купим мороженое" → бот запускает закупку с дедлайном 30 минут

**Миграция:** `2026-group-shopping.sql`

---

### 3. 👥 **Управление гостями с изменениями**
- Андрей написал "3 гостя", но сейчас едет только 1 → бот контролирует
- Автоматические напоминания: уточнить количество гостей и имена
- Система пинга до ответа (3 попытки с интервалом)
- Важно для расчёта логистики и закупок

**Миграция:** `2026-guests-pickup.sql`

---

### 4. 📍 **Координаты встречи и точки забора**
- Указать адрес + время: "завтра в 9:00, ул. Ленина 5"
- Координаты **ТОЛЬКО в цифрах**: 53.9045, 27.5615
- Бот подсказывает формат, проверяет корректность
- Заметки: "забрать вещи: рюкзак, палатку, 2 стула"
- Водитель подтверждает → напоминание за час до встречи
- Кнопка "📅 В календарь" для автодобавления

**Миграция:** `2026-guests-pickup.sql`

---

### 5. 🤖 **ИИ-менеджер групповых чатов — обучение В МОМЕНТЕ**
- Бот анализирует последние 20 сообщений группы
- **Немедленное обучение:** не ждёт 3-4 мероприятия, учится СЕЙЧАС
- Сохраняет паттерны: что сработало, что проигнорировали

**Автодействия:**
- ✅ Автозадачи: "я возьму проектор" → задача создана, назначена
- 🚗 Подсказки по логистике: "нужно место" → список свободных мест в машинах
- 🛒 Коллективная закупка: "купим мороженое?" → запуск с дедлайном
- 💬 Ответы на вопросы: "когда выезжаем?" → из живых данных
- 🤐 Молчание: обычная беседа — бот не лезет

**Обучение:** каждое действие логируется → успех/неудача → паттерны улучшаются

**Миграции:** 
- `2026-group-ai-manager.sql` (история чата, паттерны обучения)
- `api/telegram/group-handler.ts` (логика обработки)
- `api/telegram/ai-helpers.ts` (компактные промпты, экономия токенов)

---

### 6. ⏰ **Автоматические напоминания до ответа**
- Система пингует участников, пока они не ответят (макс. 3 раза)
- Напоминания:
  - Подтвердить технику безопасности
  - Уточнить количество гостей
  - Подтвердить точку забора
  - Дедлайн коллективной закупки

**Логика повторов:**
1. За 24ч до события → первое напоминание
2. Через 1 час → второе (если не ответил)
3. Через 2 часа → третье (последнее)
4. SOS организатору: кто не ответил

**Cron:** `api/cron/auto-reminders.ts` (каждые 15 минут)

---

### 7. 🎒 **Свободный ввод снаряжения с ИИ-парсингом**
- Участник пишет: "2 стула стол проектор горелка"
- ИИ парсит → `[{item: "стул", qty: 2}, {item: "стол", qty: 1}, ...]`
- Чек-лист базового снаряжения + поле для свободного текста
- Подсказка: "Можешь писать свободно — система всё обработает"
- Прогрессивная технология, не выпячиваем ИИ, просто работает

**Миграция:** `2026-equipment-ai.sql`

---

### 8. 🔄 **Синхронизация изменений программы**
- Организатор обновляет программу/меню → изменения ВО ВСЕХ сообщениях
- Участники всегда видят актуальную версию
- Расчёты пересчитываются автоматически (закупка на всех/зарегистрированных)

**Реализация:** при изменении events.program → webhook отправляет editMessageText всем, кто получал карточку

## 🚀 **Развёртывание**

### 1. Применить миграции БД
```bash
# В Supabase Dashboard → SQL Editor
# Выполнить по порядку:
2026-safety-briefing.sql
2026-group-shopping.sql
2026-guests-pickup.sql
2026-equipment-ai.sql
2026-group-ai-manager.sql
```

### 2. Настроить Vercel Cron
Добавить в `vercel.json`:
```json
{
  "crons": [{
    "path": "/api/cron/auto-reminders",
    "schedule": "*/15 * * * *"
  }]
}
```

### 3. ENV переменные
Убедиться, что установлены:
```
GEMINI_API_KEY или GOOGLE_API_KEY  — для ИИ-функций
CRON_SECRET                         — защита cron-эндпоинта
TELEGRAM_BOT_TOKEN
SUPABASE_URL
SUPABASE_SERVICE_ROLE_KEY
TELEGRAM_ADMIN_CHAT_ID
```

### 4. Подключить группу к событию
Организатор в группе:
```
/link_event <event_id>
```
Бот привяжет группу → начнёт анализировать и обучаться

## 💰 **Экономия токенов**

Все ИИ-запросы оптимизированы:
- `maxOutputTokens: 128-256` (вместо дефолтных 2048)
- `thinkingBudget: 0` — без chain-of-thought для быстрых ответов
- Промпты до 500 символов (не 3000+)
- Кеш контекста события (не пересчитываем каждый раз)
- Модель: `gemini-2.0-flash-exp` (самая быстрая и дешёвая)

**Средняя стоимость запроса:** ~0.0001$ (в 20 раз дешевле стандартной)
