# Связка сайта и Telegram-бота @campsflint_bot

Сайт «Живи в моменте» и бот **@campsflint_bot** работают как единое целое:
бот живёт на Vercel вместе с сайтом, открывает афишу как **Telegram Mini App**,
принимает заявки и обрабатывает deep-link'и событий.

## Как это устроено

```
                 ┌──────────────────────────────────────────┐
                 │            Vercel (этот проект)           │
 Пользователь ─▶ │  Сайт / Mini App                         │
                 │     │                                     │
                 │     ▼ POST /api/register ───────────────────▶ Telegram (заявка в чат заявок)
                 │                                           │
 Telegram ─────▶ │  POST /api/telegram/webhook  ◀──────────────  апдейты @campsflint_bot
 (/start и т.д.) │     └─ отвечает, открывает Mini App        │
                 │                                           │
 Бот/интеграции ◀│  GET  /api/events (единый список событий) │
                 └──────────────────────────────────────────┘
```

- **`/api/telegram/webhook`** — мозг бота: `/start`, кнопка «Открыть афишу»
  (Mini App), deep-link `event_<id>` (карточка события), `notify_<id>` (подписка
  на открытие набора).
- **`/api/register`** — заявки с сайта/Mini App уходят организатору в Telegram.
- **`/api/events`** — единый список мероприятий и статусов (источник правды).
- Данные о событиях — в `shared/events.data.js` (их читают и сайт, и API).

## Настройка (один раз, ~3 минуты)

### 1. Переменные окружения в Vercel

Vercel → проект **flint-live-in-moment** → **Settings → Environment Variables**
(для окружения Production), затем **Redeploy**:

| Переменная                 | Значение                                                            |
|----------------------------|--------------------------------------------------------------------|
| `TELEGRAM_BOT_TOKEN`       | токен **@campsflint_bot** от [@BotFather](https://t.me/BotFather)   |
| `TELEGRAM_ADMIN_CHAT_ID`   | chat_id, куда слать заявки (вы или группа заявок)                   |
| `TELEGRAM_WEBHOOK_SECRET`  | любая случайная строка (напр. `flint_9f3k2xQ`) — защита вебхука     |

> chat_id: напишите [@userinfobot](https://t.me/userinfobot); для группы —
> добавьте туда бота и возьмите отрицательный `id` группы.

### 2. Активация бота — один запрос

После Redeploy откройте в браузере (подставив свой секрет):

```
https://flint-live-in-moment.vercel.app/api/telegram/webhook?setup=1&key=<TELEGRAM_WEBHOOK_SECRET>
```

Этот вызов автоматически:
1. регистрирует webhook (`setWebhook`) → бот получает апдейты;
2. ставит кнопку-меню бота, открывающую афишу как Mini App (`setChatMenuButton`);
3. задаёт команду `/start`.

Ответ `{"ok": true, ...}` — значит бот подключён к сайту. Всё, готово: напишите
боту `/start` — он ответит и откроет афишу.

## Deep-link параметры (`?start=…`), которые шлёт сайт

| Payload           | Когда                                    | Что делает бот                          |
|-------------------|------------------------------------------|-----------------------------------------|
| `event_<id>`      | подтверждение записи / переход в бота      | карточка события + кнопка «Открыть афишу»|
| `notify_<id>`     | «Сообщить об открытии» locked-события      | подписка на уведомление об открытии     |

## Синхронизация внешних интеграций

Если нужно тянуть события в сторонние системы — берите их из единого API:

```js
const { events } = await (await fetch(
  'https://flint-live-in-moment.vercel.app/api/events'
)).json();
// events[].phase: 'open' | 'locked' | 'full' | 'past' | 'closed'
```

## Жизненный цикл мероприятия (`status` в `shared/events.data.js`)

- `locked` — анонс «под замочком»: даты уточняются, набор скоро откроется
  (на сайте — замок и «Скоро», запись закрыта).
- `open` (по умолчанию) — идёт набор, запись доступна.
- `closed` — набор закрыт вручную; прошедшие уходят в архив по дате.

Чтобы открыть набор: задайте дату и уберите `status: 'locked'` — сайт и бот
сразу покажут открытую запись.

## Локальная разработка

```bash
npm install
npm run dev        # сайт на http://localhost:3000
```

> В `vite dev` serverless-функции `/api/*` не запускаются (форма покажет
> «Заявка сохранена» без доставки). Полноценно всё работает после деплоя на Vercel.
