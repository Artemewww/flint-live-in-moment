# Связка сайта и Telegram-бота @LiveInMomentBot

Сайт «Живи в моменте» и бот работают на **одних данных о мероприятиях** и
обмениваются заявками. Ниже — как это устроено и что нужно настроить.

## Как это работает

```
                    ┌─────────────────────────────┐
                    │   Vercel (этот проект)       │
                    │                             │
  Пользователь ───▶ │  Сайт / Telegram Mini App   │
                    │        │                    │
                    │        ▼                    │
                    │  /api/register  ───────────────▶  Telegram Bot API
                    │  (заявка → организатору)    │      (сообщение в чат заявок)
                    │                             │
   Бот  ◀───────────│  /api/events                │
   (синхронизация)  │  (единый список событий)    │
                    └─────────────────────────────┘
```

1. **Единый источник событий.** Список мероприятий лежит в `src/data.ts`.
   Сайт показывает его напрямую, а бот забирает тот же список и статусы через
   `GET /api/events`. Меняете `src/data.ts` → обновляется и сайт, и бот.

2. **Жизненный цикл мероприятия** (`status` в `src/data.ts`):
   - `locked` — анонс «под замочком»: даты определяются, набор скоро откроется.
     На сайте — иконка замка и «Скоро», запись недоступна, есть кнопка
     «Сообщить об открытии» (deep-link `?start=notify_<id>`).
   - `open` (по умолчанию) — идёт набор, регистрация доступна.
   - `closed` — набор закрыт вручную.
   - Прошедшие определяются по дате автоматически (архив).

   Чтобы «открыть» мероприятие: задайте дату и уберите `status: 'locked'`
   (или поставьте `'open'`). Всё — сайт и бот сразу показывают набор.

3. **Заявки с сайта → в Telegram.** Форма регистрации отправляет данные на
   `POST /api/register`. Функция проверяет подпись Telegram (если заявка из
   Mini App) и пересылает заявку организатору в Telegram.

4. **Telegram Mini App.** Если открыть сайт кнопкой из бота, он работает как
   Mini App: личность (имя, @username) берётся из Telegram автоматически, без
   «ручного» ввода, а заявка сразу подписана и доставляется.

## Что настроить (5 минут)

### 1. Переменные окружения в Vercel

Vercel → Project → **Settings → Environment Variables**:

| Переменная                | Значение                                             |
|---------------------------|------------------------------------------------------|
| `TELEGRAM_BOT_TOKEN`      | Токен бота от [@BotFather](https://t.me/BotFather)   |
| `TELEGRAM_ADMIN_CHAT_ID`  | chat_id администратора или группы заявок             |

> Узнать `chat_id`: напишите боту [@userinfobot](https://t.me/userinfobot),
> либо для группы — добавьте бота в группу и посмотрите `getUpdates`.

После добавления переменных сделайте **Redeploy**, чтобы они применились.

### 2. Кнопка Mini App в боте (BotFather)

Чтобы сайт открывался прямо внутри Telegram:

1. [@BotFather](https://t.me/BotFather) → `/mybots` → выберите бота →
   **Bot Settings → Menu Button → Configure menu button**.
2. Вставьте URL сайта на Vercel (например `https://ваш-проект.vercel.app`).
3. Задайте подпись кнопки, напр. «🗓 Афиша».

Теперь у бота появится кнопка-меню, открывающая афишу как Mini App.

### 3. Синхронизация событий в боте

В коде бота (он у вас отдельно) забирайте список событий с сайта:

```js
const res = await fetch('https://ваш-проект.vercel.app/api/events');
const { events } = await res.json();
// events[].phase: 'open' | 'locked' | 'full' | 'past' | 'closed'
// events[].isOpen — можно ли записываться
// events[].botDeepLink — https://t.me/LiveInMomentBot?start=event_<id>
```

Так бот всегда показывает те же мероприятия и статусы, что и сайт.

## Deep-link параметры (`?start=...`), которые шлёт сайт

| Payload             | Когда                                   | Что делать боту                         |
|---------------------|-----------------------------------------|-----------------------------------------|
| `event_<id>`        | подтверждение записи / переход в бота    | показать событие `<id>`, оформить бронь |
| `notify_<id>`       | «Сообщить об открытии» locked-события    | подписать на уведомление об открытии    |
| `year_planning_modal` | заявка на сезон из годового календаря   | показать план сезона                    |

## Локальная разработка

```bash
npm install
npm run dev        # сайт на http://localhost:3000
```

> В режиме `vite dev` serverless-функции `/api/*` не запускаются — форма
> покажет «Заявка сохранена» (без доставки). Полностью, вместе с `/api`,
> проект работает после деплоя на Vercel (или через `vercel dev`).
