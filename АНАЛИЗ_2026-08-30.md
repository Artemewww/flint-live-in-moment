## 1. О проекте

**«Живи в моменте» (FLINT)** — афиша, календарь и платформа управления событиями для **трезового сообщества осознанного общения** (Минск, Беларусь). Объединяет сайт, Telegram-бота `@campsflint_bot` (через webhook на Vercel) и Telegram Mini App. Жизненный цикл события: `locked` → `open` → `past`/`closed`. Ядро: `shared/events.data.js`.

## 2. Технологический стек

| Слой | Технология |
|---|---|

| Инфраструктура | Vercel Hobby (cron 1×/день) |

### Ограничения Vercel Hobby
- **12 serverless-функций max** → сейчас **11/12** (запас 1).
- **Cron 1×/день** (9:00 МСК) → авто-напоминания только ежедневно; частые кроны не работают.
- Все новые фичи — в существующие файлы (`profile.ts`, `admin/*.ts`).

### 6.2 Deep-link payload
| Payload | Когда | Что делает |
|---|---|---|

## 11. Архитектурные решения (приняты)

| № | Решение | Почему |
|---|---|---|
| 1 | **Один бот — serverless webhook.** `bot/` → `bot.legacy/` | Один деплой (Vercel), один env, один источник правды |
| 2 | **Состояние диалога — гибрид** (callback_data + `bot_sessions`) | Serverless без памяти между запросами |
| 3 | **Картинки — Supabase Storage** (бакет `event-images`) | Единое хранилище с БД |
| 4 | **Все новые фичи → в существующие файлы** | Лимит 12 функций на Hobby |
| 5 | **RLS на всех таблицах** | Безопасность: anon-доступ закрыт |
| 6 | **Бот замолкает → работа в Mini App** (28.08) | UX: не метаться между ботом и приложением |
| 7 | **Пул ключей Gemini с авто-ротацией** (28.08) | Бесплатный тир — одна модель/сутки |

## 12. Ограничения и риски

### Инфраструктурные
| Ограничение | Влияние | Решение |
|---|---|---|
| 12 функций на Hobby | Нет места для новых эндпоинтов | Все фичи в `profile.ts`/`admin/*.ts` |
| Cron 1×/день | Автонапоминания только ежедневно | Upgrade на Pro / внешний cron |
| In-memory rate limiter | Race condition; не кластеризуется | Redis / Vercel KV |
| setInterva в serverless | Утечка памяти | Пассивная очистка (lazy) |
| webhook.ts = 8801 строк | Сложно поддерживать, холодный старт | Рефакторинг (ограничен) |

### Безопасность

За ~2 месяца (июль–август 2026, **466 коммитов**) проект FLINT превратился из MVP «сайт-афиша + бот» в **полную экосистему трезового сообщества** с:
