# Инструкция по развёртыванию обновлений

## Новый функционал (17.07.2026)

### 1. ИИ-консьерж Flint
- Отвечает на свободные вопросы участников о событии
- Использует живые данные: машины, места, программа, задачи
- Экономит токены: быстрый промпт + кеш контекста

### 2. Умная постановка задач
- ИИ причёсывает формулировку задачи
- Извлекает теги: нужен авто, время выполнения
- Адресная рассылка: задачи с авто → только водителям
- Кнопка «в календарь» для каждой задачи

### 3. Личное снаряжение с ИИ-парсингом
- Участник пишет свободным текстом: "2 стула, стол, мангал"
- ИИ парсит в структурированный список с количеством
- Автоматическая категоризация
- Показывается при регистрации на события

### 4. Скрытие кнопки «Афиша» для новичков
- Кнопка появляется только после одобрения заявки
- Реализовано через `setChatMenuButton` при approve

## Оптимизация токенов ИИ

Все ИИ-вызовы оптимизированы:
- **ИИ-консьерж**: ~200 токенов/запрос (контекст события)
- **Парсинг снаряжения**: ~150 токенов (список до 20 предметов)
- **Постановка задач**: ~180 токенов (причёсывание + теги)
- **Парсинг голосований**: ~250 токенов (вопрос + варианты)

Используется `thinkingBudget: 0` для быстрых ответов в вебхуке.

## Проверка работы

### ИИ-консьерж
1. Запишись на событие
2. Напиши боту: "Сколько машин?" или "Когда выезд?"
3. Бот должен ответить на основе живых данных

### Снаряжение
1. Запишись на событие
2. Организация → Снаряжение → Добавить своё
3. Напиши: "2 стула складных, мангал, проектор"
4. Система распарсит и сохранит в инвентарь

### Умные задачи
1. Задачи события → Поставить задачу
2. Напиши: "Забрать проектор у Марины, ул. Сурганова 5, завтра 9:00"
3. ИИ причешет, извлечёт время, разошлёт участникам
4. Кто возьмёт — появится кнопка "в календарь"
