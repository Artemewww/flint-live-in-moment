## 2. БАЗА ДАННЫХ (Supabase)

### Основные таблицы
- `members` — участники клуба (расширена: `points`, `level`, `achievements`, `allergies`, `liked_foods`, `activity_preferences`, `sleep_schedule`)
- `events` — события
- `registrations` — заявки на события
- `referrals` — реферальные связи
- `feedback` — отзывы
- `interests` — интересы
- `program_votes` — голоса за программу

### Новые таблицы (2026-dietary-profile.sql)
- `event_menus` — меню мероприятия по дням и приёмам пищи
- `menu_votes` — голосование за блюда
- `activities` — библиотека активностей
- `event_schedules` — расписание мероприятия
- `event_roles` — роли участников на мероприятии
- `role_templates` — шаблоны ролей
- `event_chats` — групповые чаты Telegram
- `points_log` — журнал начисления баллов
- `achievements` — каталог достижений

## 3. TELEGRAM БОТ

### Команды
- `/start` — главное меню, регистрация
- `/events` — ближайшие мероприятия
- `/profile` — профиль с баллами и достижениями
- `/diet` — анкета питания
- `/preferences` — предпочтения (активности, сон)
- `/help` — помощь

### Хендлеры
- `start.js` — онбординг, реферальные ссылки
- `events.js` — афиша, регистрация
- `registration.js` — пошаговая регистрация
- `profile.js` — профиль, достижения
- `diet.js` — анкета питания (тип, продукты, аллергии, гости)
- `preferences.js` — активности, режим сна, медицинские ограничения
- `roles.js` — выбор ролей на мероприятии
- `chats.js` — создание групповых чатов (заглушка)

## 4. АДМИНКА (Next.js + React)

### Вкладки
- **Обзор** — статистика по всем событиям, карточки (участники, оплата, подтверждения, готовность)
- **Участники** — фильтры (все/ожидают/подтверждены/оплатили/явка), отзывы, копирование контактов
- **Логистика** — транспорт, палатки, снаряжение, меню, делёж расходов
- **Настройки** — статус события, перенос дат, доступ, объявления

### Ключевые функции
- ИИ-генерация программы и обложки
- ИИ-генерация меню под профили участников
- ИИ-генерация списка закупки
- Автоматическое начисление баллов при отметке явки
- Ручное начисление баллов (модалка)
- Рассылка меню, координат, объявлений
- Управление аудиторией клуба (костяк, блокировка, удаление)

## 5. API ЭНДПОИНТЫ

### Serverless Functions (10/12)
1. `api/register.ts` — регистрация
2. `api/events.ts` — афиша для участников
3. `api/admin/events.ts` — CRUD событий, логин/логаут
4. `api/admin/registrations.ts` — заявки, участники, ручное начисление баллов
5. `api/admin/broadcast.ts` — рассылка в Telegram
6. `api/telegram/webhook.ts` — webhook для бота
7. `api/telegram/webhook.ts?setup=1` — установка webhook (был отдельный setup.ts; убран из-за лимита 12 функций Hobby)
8. `api/ai.ts` — ИИ-генерация (Gemini)
9. `api/profile.ts` — **универсальный** (питание, предпочтения, роли, чаты, погода, расписание, метрики, интеграции)
10. `api/cron/reminders.ts` — автоматические напоминания

### Actions в `api/profile.ts`
- `onboard` — онбординг профиля
- `diet` / `save_diet` — профиль питания
- `suggest` — чек-лист продуктов
- `menu` — получить меню
- `generate` — ИИ-генерация меню
- `receipt` — распознавание чека
- `recipe` — генерация рецепта
- `rate` — оценка блюда
- `save_activity_preferences` — предпочтения по активностям
- `save_sleep_schedule` — режим сна
- `get_event_roles` — роли на событии
- `save_event_role` — сохранить роль
- `delete_event_role` — удалить роль
- `get_profile` — профиль участника
- `add_points` — начисление баллов
- `metrics` — метрики и аналитика
- `integrations` — внешние сервисы (заглушка)
- `create_event_chat` — создать групповой чат
- `get_event_chats` — получить чаты события
- `get_weather` — погода (Open-Meteo)
- `generate_schedule` — ИИ-генерация расписания

## 7. КАК РАБОТАТЬ С ПРОЕКТОМ

### Локальная разработка
```bash
# Бот
cd bot && npm install && npm start

# Веб-сайт + API
cd src && npm install && npm run dev

# Миграции БД (выполняются автоматически через Supabase)
# См. supabase/migrations/2026-dietary-profile.sql
```

### Деплой
```bash
# Коммит и пуш в main → Vercel auto-deploy
git add -A
git commit -m "feat: описание"
git push origin main
```

### Важно
- **Не создавать новые Serverless Functions** — использовать `api/profile.ts`
- **Все новые фичи** — через существующие эндпоинты
- **БД изменения** — через миграции в `supabase/migrations/`
